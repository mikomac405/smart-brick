# Smart Brick

Custom firmware and app for the [ESP32 CAMERA ROBOT STM32 DEVELOPMENT KIT](https://tscinbuny.com/products/tscinbuny-esp32-kit-for-arduino-camera-robot-stm32-development-kits-programmable-robot-educational-kit-4wd-ackermann-chassis-obstacle-avoidance-line-tracking-robotic-with-codes).

This project aims to transform this educational robotic toy into a fully autonomous device.
